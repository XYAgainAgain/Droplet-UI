# Droplet UI

Droplet UI is a **zero-runtime-dependency** Web Components library for soft, tactile interfaces. It combines friendly controls with expanded soft-body physics surfaces, so every press, toggle, drag, and keystroke settles with a wobble. I'll make a cute logo for it soon, just you wait.

This project is a fork of **[Jelly UI](https://github.com/jelly-org/ui)** by [bmson](https://github.com/bmson), created because my brain simply couldn't accept several limitations of the wonderful (if under-maintained) original project.

It is written in **strict TypeScript**, bundled with **Vite** into a single ESM file (it's in `dist/`) plus type declarations, and covered by **real browser tests** (Vitest + Playwright). Consumers still get the whole library in one tidy `<script>` tag, and the goal is that anyone currently using Jelly UI will be able to plop Droplet UI right into their project with full backwards compatibility plus many more customization options.

*Development is in progress; currently very early stages! Please be patient! **THE JIGGLY UI COMETH!***
